# Elevvo Front-End Web Development Projects

Welcome to my front-end web development portfolio, created as part of the Elevvo internship tasks.

This repository contains five completed projects demonstrating my practical skills in building responsive, interactive, and user-friendly web interfaces using HTML, CSS, and JavaScript.

## Projects

### 1. Collapsible Sidebar
A modern dashboard interface featuring a collapsible navigation sidebar and interactive navigation.

### 2. Contact Form
A stylish, responsive contact form with input validation and submission feedback.

### 3. TaskFlow Website
A productivity application landing page featuring a hero section, features, testimonials, pricing plans, and responsive layouts.

### 4. Personal Blog Homepage
A responsive blog homepage featuring article cards, search, category filtering, pagination, and a newsletter form.

### 5. Masi AI Landing Page
A modern AI product landing page featuring a responsive layout, light and dark themes, product sections, testimonials, and pricing.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- DOM Manipulation
- Local Storage

## Getting Started

Each project is contained in its own folder.

To view a project:

1. Open the project folder.
2. Locate `index.html`.
3. Open `index.html` in your web browser.

No additional installation is required for these static projects.
